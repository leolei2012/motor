# 无感 FOC 切闭环崩溃修复 —— SMO 重写与启动切换（2026-09-23）

> 前置：`问题描述_无感FOC切闭环崩溃.md` 描述的是「800rpm 切闭环 16ms 崩」的故障状态。
> 本文记录那之后针对根因的完整重写，以及当前已通过主机回归 + Keil 编译（0 error / 0 warning）
> 的状态。实物持续运行与负载扰动的最终结论仍需上板验收。

## 一、本次改了什么（概览）

目标转速从 800rpm 提到 **1000rpm**，开环只拖到 **300rpm**，切闭环后由速度环斜坡升到 1000rpm。
核心变化集中在四块：**SMO 观测器重写**、**开环→闭环切换机制**、**PLL/速度环增益**、**电压重建与保护**。

| 模块 | 改动 |
| --- | --- |
| `mcl_observer_smo.c/.h` | 整段重写：电流预测顺序、自适应带宽滤波、有符号相位补偿、负转速 π 反转 |
| `mcl.c`（开环自动切换） | 升余弦 S 形斜坡、15rpm 牵入地板、SMO 资格判定、相位偏差渐消、电流/斜坡过渡 |

## 二、SMO 重写的关键点

旧 SMO 的根因链（详见问题描述文档）：开环拖动期间 `w_est≈0` → 滤波系数 `Kslf` 被 clamp 到下限 →
反电动势 e 不收敛 → 角度不准 → 死循环；且固定相移 71.57° 只在 `|ω|/ωc=1` 处成立。

新实现：

1. **电流预测顺序**：先用上一周期电压 `v[k-1]` 与旧 E/Z 预测当前电流 `i_hat[k]`，再与
   实测 `i[k]` 比较得到误差和新的滑模修正 Z。旧顺序把跨采样时刻的电流差混进了反电动势估计。
2. **带宽自适应变慢**：滤波系数每拍 0.001（16kHz 下约 62.5ms），避免「滤波相移 → 差分转速 →
   滤波带宽」之间的正反馈；原始估速平滑每拍 0.02（约 3ms）。
3. **相位随速度/带宽之比及方向变化**：`Efinal/Etrue = H²/(1+H)`（连续域 `H=1/(1+j·r)`，
   `r=|ω|/滤波带宽`），滞后 `atan(r)+atan(r/2)=atan2(3r, 2-r²)`；仅 `r=1` 时为 71.565°。
   反向时额外补 π 反转（反电动势负转速翻转）。
4. **开环速度提示保留符号**：`seed_omega` 有符号，直到调用方显式写 0 才释放；不再由单拍
   角增量触发释放。原始 EMF 角差分用于估速，补偿角变化不进速度差分。
5. **`seed` 按两级不同稳态幅值/相位预置**，不再把两级滤波器都设成完整物理 EMF；`Efinal` 是
   滤波后的内部状态（稳态幅值 ≈0.316×ωλ），不能直接与完整物理反电动势 3.0V 比较。
   正常自动启动**不调用** `seed`。

## 三、开环→闭环切换机制（`mcl.c`）

- **牵入**：斜坡从 15rpm 地板起步（1.25Hz 场频，转子从任意位置可牵入），用升余弦 S 形斜坡
  （`ol_rpm = max/2·(1-cos(π·t/t_ramp))`），起点/终点加速度为 0。旧「10% 地板 + 线性斜坡」的
  80rpm 跳变和终点 α 突变会让转子打滑或激发 I/F 摆动（ω_n≈4Hz），实测反电动势停在 0.43~0.7V
  （转子只在 100~200rpm 爬行）。
- **资格判定（float SMO 专属）**：开环结束后不因时间到就撒手，而是连续 20ms 满足——估速与拖动
  速度偏差 <20%、二级 EMF 幅值在理论稳态值的 0.5~1.5 倍、与开环角差 <100°——才切闭环；最多等 0.5s，
  失败锁存 `MCL_FAULT_STALL`。这避免把「被强制场速」误当成「观测器已收敛」。
- **相位衔接**：切换时 PLL 同步相位、积分速度与 `speed_est_fast` 历史；记录开环角相对 PLL 角的
  最短偏差 `switch_phase_offset`，在 0.5s 内逐渐归零（不瞬间旋转 d/q PI 状态）；电流参考同期从
  0 过渡（速度模式），斜率从当前开环转速起、积分清零。
- **速度指令斜坡**（`speed_ramp_rpm_s`）：速度环跟踪的指令向 `speed_ref_rpm` 斜坡（500 rpm/s，
  300→1000 约 1.4s），避免阶跃指令激发摆动。

## 四、PLL 与速度环增益

| 项 | 旧值 | 新值 | 说明 |
| --- | --- | --- | --- |
| PLL kp/ki | 40 / 200 | **200 / 10000** | ωn≈100rad/s(~16Hz)、ζ≈1。旧 40/200 在加减速时相位滞后到触发重拖；主机带载回归里旧值反复重拖 |
| 速度环 kp/ki/kd | 0.005/0.002/0.5 | **0.005/0.02/0** | 取消对未滤波估速的差分放大；闭环电流上下限改为 ±3A（与开环拖动一致，额定 4A） |
| 速度指令斜坡 | 无 | **500 rpm/s** | 见上 |

## 五、电压重建与保护

- **观测器输入电压从最终占空比重建**：`v_alpha_prev`/`v_beta_prev` 由最终三相 duty 反推（含
  0.95 调制比例与钳位），下拍乘母线电压转 V。旧实现直接缓存未钳位的 `v_alpha/v_beta`，过调制时
  观测器输入与实际输出电压不符。
- **SVPWM 输出钳位**：负数/NaN/越界占空比在转无符号整数前先钳到 [0, max_duty]，防 CCR>ARR
  输出常开导致过流。
- **保护启用并锁存**：过流 4A、过压 48V、欠压 8V；`fault_stop_time=0`（锁存故障，显式清故障后才能
  重启）。无温度传感器，不启用依赖虚假温度读数的过温保护。开环收敛失败由 mcl 独立超时报 STALL。

## 六、Ortega 电阻自适应（备注）

`mcl_observer_ortega.c` 新增了 VESC 式电阻自适应观测器（功率平衡法，论文 DOI 10.1002/acs.2587），
结构体加了 `r_est`/`r_est_state`/`speed`，并暴露 `mcl_observer_ortega_set_speed()`。
但 `ortega_update` 内当前**仍用固定 R**（`R = params.resistance`，注释「电阻自适应回填实测导致
磁链/速度震荡，暂回退」）。即：自适应代码已就位但未启用，是预留方向，当前板级走 SMO，不涉及。

## 七、主机回归结论（见 `third_party/mcl/docs/smo_validation.md`）

- SMO 独立电压/电流序列正转 100/300/800/2000rpm、反转 300/800/2000rpm 全通过；800rpm 稳态角差约 1.05°。
- 完整 PMSM 模型 800rpm 风扇负载(~1.7A)、初始角 0/1/2.5rad，各 10s 只切一次闭环、末秒平均 800rpm。
- 惯量 0.0001→0.0002、空载 300rpm、带载 -800rpm、20mA 确定性扰动均通过。
- 堵转约 2.05s 报 STALL、平均相电压归零；Keil ARMClang 6.24 0 error / 0 warning。

## 八、实物验收关注点（未上板验证）

- ISR 最坏执行时间未实测，需确认 ≤62.5µs（新增一次 atan2f 相位补偿，必要时上 CORDIC）。
- 开环期间界面转速是强制场速，不能当作真实转子转速；重点记录 `state/fault`、`ol_stage`、
  `ol_lock_timer/ol_wait_timer`、PLL 估速、SMO `w_est/dt`、`phase`、`filter_step`、控制角、id/iq、vbus。
- 正常应一次 `ol_stage=2→0` 后持续运行；故障锁存先读现场，不要绕过保护重试。
- 增益（PLL 200/10000、速度环 0.005/0.02、斜坡 500rpm/s）是主机模型整定，需按实物惯量/负载微调。
