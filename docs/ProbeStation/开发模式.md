# 固件调试开发模式（固件 agent + ProbeStation 协同）

> 记录「固件 agent 产出语义 + ProbeStation 观测/测试 + 调试 agent 读原始值」这套协同开发方式，
> 便于以后用同样的模式开发新项目。

## 1. 角色分工

| 角色 | 职责 |
|---|---|
| 固件开发 agent | 写固件、在 Modbus 上挂寄存器、**产出语义清单 YAML + Excel** |
| ProbeStation（平台） | 只提供**原始数据读写**（读/写 Modbus 原始值），不解析语义 |
| 调试 agent | 用 MCP 工具读原始值，**对照 YAML** 自己理解语义 |
| 固件工程师 | 用 Excel 视图审阅、补描述 |

核心原则：**平台只做「读原始值 / 写原始值」，不做翻译**。语义（名称/类型/缩放/枚举）写在 YAML 里，
是调试 agent 之间的说明书。

## 2. 端到端工作流

```
① 写固件 + 在 Modbus 上挂寄存器（含调试寄存器）
        │
        ▼
② 产出语义清单 YAML（唯一真源）+ Excel（给人审阅的视图）
        │
        ▼
③ 调试 agent：用 MCP 读/写原始值，对照 YAML 理解数据
```

## 3. 固件侧约定

### 3.1 Modbus 寄存器挂载

- 固件用 Modbus RTU 从站（本工程用 `third_party/MB-RTU`），寄存器映射集中在 **adapter 层**
  （`third_party/bootloader/adapter/modbus/`），业务引擎不感知 Modbus。
- 功能码：FC03 读保持寄存器（状态/调试），FC41 自定义（OTA/IAP）。

### 3.2 寄存器地址段划分（约定）

| 地址段 | 用途 |
|---|---|
| 0x0000~0x00FF | **产品寄存器**（状态、参数、控制） |
| 0xE000~0xEFFF | **调试寄存器**（调试 agent 专用，不进产品文档） |

调试地址段 0xE000~0xEFFF 固定给调试用，调试 agent 想观察什么就挂什么；产品功能寄存器
从低地址正常排布，两者互不干扰。

### 3.3 调试寄存器建议内容

调试 agent 通常想观察：

1. **分区/链接配置**（静态常量，验证链接地址对不对）：APP 地址/大小、下载槽地址/大小、META 地址、页大小。
2. **元数据内容**（动态，验证 META 读写）：magic、app_size、app_crc32、flags。
3. **运行时进度**（动态，观察 IAP）：下载已收/总字节。
4. **状态机/错误码**（已有产品寄存器可覆盖）。

32 位值按 Modbus 大端拆成相邻两个 16 位寄存器（高 16 位在前），YAML 里用 `uint32` 类型，
平台自动合并。

## 4. 语义清单（YAML + Excel）

- **YAML 是唯一真源**（git 版本化），格式见 ProbeStation 的《03-语义清单契约-YAML规范.md》。
- **Excel 是 YAML 的导出视图**（给人看），列 = name/address/data_type/access/description/enum。
- 字段要点：
  - `firmware.version` 必填，用于「清单 == 固件」新鲜度核对。
  - 寄存器 `name`（snake_case）、`address`（0x 十六进制）、`data_type`（uint16/uint32…）。
  - 状态用 `enum`，位标志用 `bitfield`，缩放用 `scale`，自清零命令用 `volatile`。

## 5. 文件组织

```
docs/ProbeStation/
├── <固件>.yaml        # 语义清单（唯一真源）
├── <固件>.xlsx        # Excel 视图（导出）
└── 开发模式.md         # 本文档
```

> 当前 YAML↔Excel 双向同步脚本 ProbeStation 侧尚未提供，Excel 暂按规范列结构手动生成；
> 待脚本就绪后改用脚本，保证两文件严格同步。

## 6. 新项目接入清单

- [ ] 固件挂 Modbus 从站 + adapter 层集中寄存器映射。
- [ ] 划分地址段：产品寄存器 0x0000 起，调试寄存器 0xE000~0xEFFF。
- [ ] 按需要挂调试寄存器（分区/元数据/进度/状态）。
- [ ] 产出 `docs/ProbeStation/<固件>.yaml`（含 `firmware.version` + 每个寄存器的 name/address/data_type/enum/bitfield）。
- [ ] 生成对应 Excel 视图。
- [ ] 在 ProbeStation 建 RTU 设备（串口 + 从站地址）+ 寄存器组，开始轮询。
- [ ] 调试 agent 用 MCP 读原始值，对照 YAML 理解语义。

## 7. 范例：bootloader

- 语义清单：`docs/ProbeStation/bootloader.yaml`
- Excel 视图：`docs/ProbeStation/bootloader.xlsx`
- 产品寄存器 0x0000~0x0004：state / boot_reason / app_valid / dl_valid / error（5 个状态）。
- 调试寄存器 0xE000~0xE016：分区配置 + META 内容 + 下载进度（13 个）。
- 实现：`bootloader-v1.0/third_party/bootloader/adapter/modbus/bl_adapter_modbus.c`
