# 规格符合性测试报告

## 1. 概述

| 项 | 内容 |
| --- | --- |
| 测试对象 | bootloader 库（`third_party/bootloader/`）+ bootloader-v1.0 固件 |
| 依据文档 | [01-architecture](01-architecture.md) / [02-memory-layout](02-memory-layout.md) / [03-iap-protocol](03-iap-protocol.md) |
| 状态 | 规格已锁定，测试用例待执行（「结果」列填 `PASS` / `FAIL` / `N/A`） |

## 2. 规格基线（锁定项）

1. 传输无关引擎 + 适配器（库不绑协议）
2. 双槽 copy 模式 + 单槽流式模式（宏切换）
3. 校验只依赖 magic + size + CRC32（**无版本号**）
4. 不做 run-confirm 回滚
5. 不做 flash_read 抽象（假定内存映射）
6. 库名 `bootloader`，目录 `third_party/bootloader/`
7. port/stm32g4 + adapter/modbus 完整可编译
8. 不做跨断电续传（仅会话内可查进度）

## 3. 测试环境

- 硬件：STM32G474VET6 开发板（ATK-DMG474）
- 工具：Keil MDK-ARM、Modbus RTU 上位机、串口工具、逻辑分析仪（可选）

## 4. 规格符合性测试用例

### A. 启动与跳转（含上电校验）

| 编号 | 规格项 | 测试方法 | 期望结果 | 结果 | 备注 |
| --- | --- | --- | --- | --- | --- |
| A1 | 上电跳转 | APP1 有效，烧录后上电 | 跳转 APP1 运行 | | |
| A2 | **上电校验 CRC** | 篡改 APP1 中 1 字节（不更新 META）后上电 | CRC 不匹配，**不跳转**，进 IAP | | 核心安全项 |
| A3 | 空 flash 首启 | 全新芯片（META 全 0xFF）上电 | magic 无效，进 IAP 等待下载 | | |
| A4 | 强制 IAP | 置 IAP_REQUEST 标志或按键后上电 | 忽略 APP 有效性，直接进 IAP | | |

### B. 双槽 copy 模式（下载到 APP2 → copy APP1）

| 编号 | 规格项 | 测试方法 | 期望结果 | 结果 | 备注 |
| --- | --- | --- | --- | --- | --- |
| B1 | START | 上位机发 FC41 START(size, crc) | 回 OK，进入 RECEIVING | | |
| B2 | 攒页写 | 发满 16 块（16×128B=2KB） | 擦 1 页 + 写 1 页 APP2 | | |
| B3 | END+校验 | 发完所有块 + END | 整图 CRC 过 → copy APP2→APP1 → commit | | |
| B4 | CRC 失败 | 上位机故意给错 crc32 | 回 IAP，APP1 原封不动 | | |
| B5 | 块号不连续 | 跳过某块号 | 回 BAD_BLOCK | | |
