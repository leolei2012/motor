# 编码规范

> 适用 MC_BASE 仓库下所有 C 工程（motor_control、bootloader）。目标：统一风格、可读、可维护。

## 1. 文件组织

- 一个模块一对 `.c/.h`，头文件放 `include/`，实现放 `src/`。
- 头文件保护用宏：`#ifndef <模块大写>_H` / `#define` / `#endif`，结尾带注释。

```c
#ifndef HAL_GPIO_H
#define HAL_GPIO_H
...
#endif /* HAL_GPIO_H */
```

- include 顺序：先本模块头，再项目头，最后标准/第三方头，空行分组。

```c
#include "drv_usart2.h"

#include "hal_usart2.h"
#include "uart_control.h"

#include <string.h>
```

## 2. 命名规范

| 对象 | 规则 | 示例 |
| --- | --- | --- |
| 函数 | 层前缀 + 模块 + 动作，小写下划线 | `drv_usart2_send`、`hal_gpio_write` |
| 模块内 static 函数 | 不加层前缀 | `on_rx_done`、`refresh_status` |
| 变量（局部/static） | 小写下划线，static 加 `s_` 前缀 | `led_last`、`s_frame_ready` |
| 全局变量 | 加 `g_` 前缀 | `g_boot_uart` |
| 类型（struct/enum/typedef） | 小写下划线 + `_t` 后缀 | `drv_output_id_t`、`bl_status_t` |
| 宏/常量 | 全大写 + 下划线 | `UART_RX_BUF_SIZE`、`BL_META_MAGIC` |
| 枚举值 | 全大写 + 模块前缀 | `DRV_OUTPUT_LED`、`HAL_GPIO_LEVEL_HIGH` |

- 命名自解释，避免 `tmp1`、`flag2`；缩略语统一（`init`/`poll`/`set`/`get`/`enable`/`disable`）。

## 3. 类型

- 一律用 `stdint.h` 定长类型：`uint8_t` / `uint16_t` / `uint32_t` / `int32_t` 等，不用 `int`/`long`/`char`（除字符串）。
- 布尔用 `bool`（`stdbool.h`），不用 `int`/`uint8_t` 冒充。
- 字面量显式带后缀：`0x800u`、`500u`、`1u << 0`。

## 4. 格式

- 缩进 4 空格，不用 Tab。
- 花括号 Allman 风格（独立一行）：

```c
if (len == 0u)
{
    return;
}
```

- 单行语句也加大括号（防悬挂 else 与宏展开坑）。
- 运算符两侧加空格；`=` 等号可用空格对齐（可选）。
- 每行建议 ≤ 100 字符。
- switch 每个 case 独立块，有 default。

## 5. 注释（全部 doxygen 风格）

**只允许两种注释，禁止裸 `//` 和裸 `/* ... */`：**

| 写法 | 用途 |
| --- | --- |
| `/** ... */` | 块注释：文件头、函数、结构体、枚举、宏、分节分隔线 |
| `/// ...` | 行注释：行内「为什么」、简短说明 |
| `/**< ... */` | 行尾注释：结构体字段、枚举值 |

**文件头**

```c
/**
 * @file    drv_usart2.h
 * @brief   USART2 串口功能驱动
 */
```

**函数**

```c
/**
 * @brief  发送一帧数据
 * @param  self 串口对象
 * @param  buf  待发送数据
 * @param  len  字节数
 * @return true 成功
 */
bool drv_usart2_send(drv_usart2_t *self, const uint8_t *buf, uint16_t len);
```

**结构体 / 枚举（字段与枚举值用行尾 `/**< */`）**

```c
/** 串口驱动对象 */
typedef struct
{
    struct uart_control uart;   /**< 内嵌 uart_control */
    uint8_t rx_buf[256];        /**< 接收缓冲 */
} drv_usart2_t;

/** 错误码 */
typedef enum
{
    BL_OK = 0,      /**< 成功 */
    BL_ERR_CRC,     /**< CRC 校验失败 */
} bl_err_t;
```

**宏 / 常量**

```c
/** 接收缓冲大小 */
#define DRV_USART2_RX_BUF_SIZE 256u
```

**分节分隔线（也用 doxygen 块注释）**

```c
/** ===== 下载引擎状态 ===== */
```

**行内「为什么」注释（用 `///`）**

```c
/// 不在此 re-enable，由上层处理完帧后统一恢复
self->frame_ready = true;
```

- 注释写「为什么」，不写「做了什么」。
- 分组可用 `@name` + `@{`/`@}`（可选）。

## 6. 常量与魔法数

- 禁止裸魔法数，必须命名：

```c
#define UART_RX_BUF_SIZE 256u
#define BOOT_META_MAGIC  0x4D435031u
```

- 引脚、地址、超时、缓冲大小全部进 `bsp_config.h` / `*_cfg.h` / `*_config.h`。
- 相关常量用 `enum` 或连续宏，集中一处。

## 7. 错误处理与健壮性

- 函数返回错误码（`*_err_t` 枚举或 `bool`），调用方必须检查。
- 指针参数入口判空。

```c
void drv_output_set(drv_output_id_t id, bool on)
{
    if (id >= DRV_OUTPUT_COUNT)
    {
        return;
    }
    ...
}
```

- 数组下标、枚举值越界前校验。
- 中断/回调里只做轻量操作（置标志），重活丢主循环 poll。

## 8. 头文件与依赖

- 头文件最小包含：只 include 自己真正用到的。
- 上层头文件不暴露下层实现细节（不把 `stm32g4xx_hal.h` 暴露给 app/middleware）。
- 每个 `.c` 都包含自己的 `.h`。
- 用 `static` 限制模块内可见性。

## 9. 其他约定

- 系统时钟 170 MHz，所有定时参数基于此。
- 固件版本号定义在 `config/project_config.h`。
- 中断处理函数名与启动文件向量表一致（`USART2_IRQHandler` 等）。
- 结构体初始化用指定初始化器 `{ .field = value }`。
