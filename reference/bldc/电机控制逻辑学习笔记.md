# VESC 电机控制固件 · 完整学习笔记

> 工程路径：`reference/bldc/`
> 性质：开源无刷电机（BLDC/PMSM）控制器固件 VESC（Benjamin Vedder）
> 平台：ChibiOS RTOS + STM32（以 F4 为主）
> 两种电机算法：`MOTOR_TYPE_FOC`（FOC 磁场定向，主力）与 `MOTOR_TYPE_BLDC/DC`（六步换相/直流）

### 0.1 核心代码目录

| 目录 / 文件 | 职责 |

| `motor/mc_interface.c/.h` | 电机接口层：状态机、控制模式、故障检测、限流 |
| `motor/mcpwm_foc.c/.h` | FOC 控制层（电流环跑在中断里） |

| `ChibiOS_3.0.5/` | 第三方 RTOS（可忽略） |

### 0.2 是否包含 SMO（滑模观测器）？

**没有。** 无感 FOC 用的是**磁链观测器（Flux Observer）+ PLL（锁相环）**，低速用 **HFI 高频注入**，BLDC 用**反电动势过零检测**。观测器类型枚举见 `datatypes.h:128-136`：

```c
typedef enum {
    FOC_OBSERVER_ORTEGA_ORIGINAL = 0,
    FOC_OBSERVER_MXLEMMING,
    FOC_OBSERVER_ORTEGA_LAMBDA_COMP,
    FOC_OBSERVER_MXLEMMING_LAMBDA_COMP,
    FOC_OBSERVER_MXV,
    FOC_OBSERVER_MXV_LAMBDA_COMP,
    FOC_OBSERVER_MXV_LAMBDA_COMP_LIN,
} mc_foc_observer_type;
```

核心实现 `foc_observer_update()` 在 `motor/foc_math.c:26-223`。原理是 α-β 坐标系下积分定子磁链（状态量 `x1/x2`），用磁链幅值误差反馈收敛，再用 `atan2` 求角度。代码里的 `SIGN()` 只是取符号（判方向/极性），**不是滑模的符号切换项**。

## 1. 总体架构：三层 + 多线程 + 硬件中断

### 1.1 代码分层

```
┌─────────────────────────────────────────────────────┐
│  mc_interface.c  电机接口层                          │
│  · 状态机 (OFF/DETECTING/RUNNING/FULL_BRAKE)        │
│  · 控制模式选择 (duty/current/speed/pos/brake...)    │
│  · 故障检测 + 限流计算 (lo_current_max 等)           │
├─────────────────────────────────────────────────────┤
│  mcpwm_foc.c  FOC 控制层 (跑在中断里)                │
│  · 电流采样 → Clarke/Park → 电流 PI → SVPWM          │
│  · 观测器/PLL 测角测速                               │
│  mcpwm.c  BLDC 换相层 (六步换相/反电动势过零)        │
├─────────────────────────────────────────────────────┤
│  foc_math.c  数学库                                  │
│  · 磁链观测器 / PLL / SVPWM / 角度矫正 / 弱磁 / PID   │
└─────────────────────────────────────────────────────┘
```

### 1.2 并发模型（谁跑在哪里）

| 执行单元 | 函数 | 频率/时机 | 职责 |
|---|---|---|---|
| **ADC 注入中断** | `mcpwm_foc_adc_int_handler()` | 每个 PWM 周期 | **核心电流环**（最快、最实时） |
| 1ms 定时线程 | `timer_thread` → `timer_update()` | 1 kHz | 开环启动、观测器增益、电阻观测、温度补偿 |
| HFI 线程 | `hfi_thread` → `hfi_update()` | 独立 | 高频注入的 FFT 角度解算 |
| PID 线程 | `pid_thread` | ~1 kHz | 速度环 / 位置环 |
| 故障线程 | `fault_stop_thread` | 事件驱动 | 收到故障信号 → 停机 + 记录现场 |

> 设计思想：**快环（电流）放硬件中断，慢环（速度/位置/保护）放低优先级线程**，线程间用 `utils_sys_lock_cnt()` 保护共享数据。

### 1.3 上电初始化

`main()` → `mc_interface_init(cfg_reset)`（`main.c:367`）→ 按 `motor_type` 调 `mcpwm_foc_init()` 或 `mcpwm_init()`。

关键点：**上电后必须做电流传感器 DC 校准（dccal）**，之后 `mc_interface_try_input()` 检查 `mcpwm_foc_init_done()`，未校准前拒绝输入。

## 2. 运行状态机与控制模式

### 2.1 四个状态（`datatypes.h:34-38`）

```c
MC_STATE_OFF         // PWM 关，但观测器后台跟踪反电动势
MC_STATE_DETECTING   // BLDC 检测转子位置/霍尔表
MC_STATE_RUNNING     // 正常运行
MC_STATE_FULL_BRAKE  // 三相下桥全开短路制动
```

### 2.2 控制模式决定 dq 电流目标

核心逻辑在 `mcpwm_foc.c:3338-3453`。上层命令 `set_duty/set_current/set_pid_speed/...` 设置目标值，最终转成 `id_target / iq_target`：

| 模式 | 目标来源 | 说明 |
|---|---|---|
| DUTY | 占空比 → 限幅电流 | 开环电压，用 PI 控制占空比（`:3400-3449`） |
| CURRENT | 直接 `iq_set` | 转矩控制 |
| CURRENT_BRAKE | `iq = -sign(speed)·|iq|` | 反向电流制动（`:3452`） |
| SPEED / POS | 速度环/位置环 PID 输出 → `iq_set` | 见第 8 节 |
| HANDBRAKE | 强制 `phase=0` | 锁转子（`:3602-3604`） |
| OPENLOOP* | 强制角度递增 | 启动/调试 |

## 3. FOC 核心电流环（每个 PWM 周期，中断内）

函数 `mcpwm_foc_adc_int_handler()`（`mcpwm_foc.c:2875`）。完整数据流：

```
三相电流采样 → 去偏置/标定 → Clarke变换 → (角度) → Park变换 → id/iq
   → dq电流PI + 解耦前馈 → 电压限幅(抗饱和) → 逆Park → SVPWM → 写PWM寄存器
   → (并行) 观测器测角 + PLL测速
```

1. **采样**（`:3025-3081`）：读 ADC 三相电流，减偏置（`foc_offsets_current`），乘标定系数变安培；双电阻板 `curr2 = -(curr0+curr1)`。
   - 三电阻板"高电流采样模式"：**选绝对值较小的两相，反推最大相**，扩大量程（`:3094-3110`）。

2. **Clarke 变换**（`:3298-3306`）：
   ```
   i_alpha = 2/3·ia − 1/3·ib − 1/3·ic
   i_beta  = 1/√3·ib − 1/√3·ic
   ```

3. **角度获取 → Park 变换**（`control_current`，`:4624-4625`）：
   ```
   id =  cos(θ)·i_alpha + sin(θ)·i_beta
   iq =  cos(θ)·i_beta  − sin(θ)·i_alpha
   ```

4. **d/q 电流 PI**（`:4631-4644`）：
   ```c
   vd_int += Ierr_d * ki * dt;   vd = vd_int + Ierr_d * kp;
   vq_int += Ierr_q * ki * dt;   vq = vq_int + Ierr_q * kp;
   ```
   > 注释明确：**没有 D 项**，被控对象 `1/(Ls+R)` 是一阶系统（`:4642`）。

5. **解耦前馈**（`:4646-4680`），补偿 PMSM 方程交叉耦合和反电动势：
   ```
   vd = Rs·id + Ld·did/dt − ωe·iq·Lq
   vq = Rs·iq + Lq·diq/dt + ωe·id·Ld + ωe·ψm
   ```
   三种模式：`CROSS`（只补交叉项）、`BEMF`（只补反电动势）、`CROSS_BEMF`（都补）。

6. **电压限幅 + 抗积分饱和**（`:4684-4695`）：
   - 最大电压矢量 `max_v_mag = 1/√3 · max_duty · v_bus · overmod_factor`；
   - **d 轴优先**限幅，q 轴在剩余圆 `√(max² − vd²)` 内限幅；
   - 同时限幅 `vd_int/vq_int`，防积分饱和。

7. **逆 Park → SVPWM**（`:4720-4722` → `foc_svm`，`foc_math.c:246`）：
   ```
   mod_alpha = cos·vd − sin·vq
   mod_beta  = cos·vq + sin·vd
   ```
   `foc_svm()` 扇区判断 + 七段式 SVPWM，**注入零序分量实现母线电压利用率最大化**（过调制）。

8. **短路制动优化**（`:5037-5050`）：三相占空比相等（零矢量）时直接开下桥短路，省功耗且低速制动更强。

## 4. 角度/速度估计（无感核心）

### 4.1 磁链观测器（中高速）

`foc_observer_update()`（`foc_math.c:26`）：状态量 `x1/x2` = α/β 轴定子磁链，基于电压方程 `v = Ri + dψ/dt` 积分，用磁链幅值误差反馈修正。最终 `phase = atan2(x2 − L·iβ, x1 − L·iα)`（`:217`）。6 种变体本质都是"积分 + 磁链幅值收敛 + 饱和补偿"。

### 4.2 PLL 测速

`foc_pll_run()`（`foc_math.c:225`）：锁相环跟踪角度，输出平滑转速 `m_pll_speed`。另有低延迟差分测速 `m_speed_est_fast`（`mcpwm_foc.c:3837-3859`）供 HFI 和速度环使用。

### 4.3 HFI 高频注入（零速/低速）

`control_current` 的 `do_hfi` 逻辑（`:4585-4618`）+ `hfi_update`（`:4218`）。向 d 轴注入高频电压，靠电机**凸极性（Ld≠Lq）**引起的电流响应辨识转子位置，用 FFT 解算角度。**启动时先注入辨识、iq 强制为 0，等 N/S 极性模糊解决后才允许出转矩**（`:4600-4603`）。

## 5. 启动逻辑

### 5.1 无感 FOC 开环强制启动（静止/堵转/重载启动）

实现在 `timer_update()`（`mcpwm_foc.c:4041-4135`）。"三段式"强制换向：

```
触发条件：|PLL转速| < openloop_rpm_max 持续超过 foc_sl_openloop_hyst
         ↓
启动序列（m_min_rpm_timer = t_lock + t_ramp + t_const）
  ① t_lock  锁相段：角度不动，电流建立，转子对齐
  ② t_ramp  加速段：角度按斜坡加速
  ③ t_const 恒速段：保持转速，让观测器收敛
         ↓
退出：m_min_rpm_timer 减到 0 → 切回观测器闭环
```

关键细节：
- 启动瞬间强制加 **60° 相位**（`:4112-4120`），注释说堵转时电机偏 90°，用 60° 修正；
- 加**开环助推电流** `foc_sl_openloop_boost_q`（电流环 `:3541`），上限 `foc_sl_openloop_max_q`；
- 同步**预置观测器磁链状态**（`:4127-4131`），保证切闭环无电流冲击。

### 5.2 HFI 零速带载启动

传感器模式选 `HFI_START` / `HFI` 时（`mcpwm_foc.c:3554-3599`），零速用高频注入辨识角度，比纯开环启动能带更大负载、更平稳。

### 5.3 BLDC 六步换相启动

`mcpwm_set_detect()`（`mcpwm.c:2135`）：进入 `MC_STATE_DETECTING`，依次给 6 个换相步通电，测电流差判定转子位置和霍尔表（`mcpwm_detect_currents_diff`）。无感运行用**反电动势过零 + 换相积分器（cycle integrator）**跟踪换相时刻（`mcpwm.c:1322-1341`）。

## 6. 顺风 / 逆风启动

### 6.1 顺风启动（Windmilling，电机已经在转）

**设计核心：电机停了观测器也不停。**

`MC_STATE_OFF` 分支（`mcpwm_foc.c:3684-3815`）里，电流为 0 但仍**跑观测器跟踪反电动势**（`:3705-3719`），PLL 持续测速，并把电流环积分器预置到反电动势电压（`:3795-3804`，注释明确"避免重新驱动时电流尖峰"）。

→ 效果：电机自由滑行时重新给指令，控制器已知道角度和转速，**直接无缝切入闭环**，无需重新开环。

BLDC 模式同理：`MC_STATE_OFF` 时用 FIR 滤波跟踪反电动势幅值和方向，`dutycycle_now` 跟随（`mcpwm.c:1364-1435`）。

### 6.2 逆风启动（命令方向与转动方向相反）

没有独立状态，靠三层机制自然处理：

1. 观测器始终锁定真实角度（不管朝哪转都知道相位）；
2. **换向/方向改变时先短路制动**（`:3345-3368`）：方向或调制符号变化瞬间 `duty=0` 三相短路，直到制动电流达到设定值再恢复电流控制；
3. **制动电流方向** `iq = -sign(speed)·|iq|`（`:3452`），先刹停逆风电机；
4. 转速降到观测器阈值以下 → 退回第 5.1 节开环强制启动。

## 7. 堵转（失步）处理

- **无感 FOC**：没有独立"堵转故障码"，靠**开环重启**——有电流指令但 PLL 转速持续低于阈值 → 触发第 5.1 节开环强制换相，等于"失步自动重新拖入同步"（`mcpwm_foc.c:4083-4103`）。
- **HFI**：转速低于 `foc_hfi_reset_erpm` 时清零 HFI 状态重估（`:3747-3750`）。
- **BLDC**：换相时间分布异常（最长/最短换相间隔差 > 1.2 倍）→ 判定方向错误 → 翻转方向重试（`mcpwm.c:1379-1426`）。

## 8. 速度环 / 位置环 PID

两个函数都在 `foc_math.c`。

### 8.1 速度环 `foc_run_pid_control_speed()`（`:492`）

- 目标转速 `m_speed_pid_set_rpm` 先经 **ERPM 斜坡** `s_pid_ramp_erpms_s` 逼近命令值（`:505-516`），即"加速罗"；
- 测速源可选 PLL / fast / faster（`:519-529`）；
- 标准 PID：`output = P + I + D`，D 项滤波（`:541-547`），积分抗饱和（`:556-558`）；
- 可选**禁止制动** `s_pid_allow_braking`：转速 >20 且输出 <0 时清零输出（`:564-573`）；
- 输出映射到 `iq_set = output · lo_current_max`（`:575`）。

### 8.2 位置环 `foc_run_pid_control_pos()`（`:385`）

- 角度误差用 `utils_angle_difference`（处理 360° 环绕）；
- PID + 双重 D 项（误差微分 D + 过程量微分 D_proc，都滤波），适合低分辨率编码器（`:438-465`）；
- **积分抗饱和**：`I ≤ 1 − |P|`（`:467-470`）；
- 编码器索引未找到时，用 40% 电流旋转找索引（`:484-486`）。

## 9. 弱磁控制（Field Weakening）

`foc_run_fw()`（`foc_math.c:708`）。原理：高速时反电动势逼近母线电压，电压不够用 → **注入负 d 轴电流 `id` 削弱转子磁链**，换取更高转速。

- **触发**：`|duty| > foc_fw_duty_start · l_max_duty`（`:728`）；
- 弱磁电流按占空比从 0 线性映射到 `foc_fw_current_max`（`:743-746`）；
- **防失控回退** `foc_fw_backoff`：iq 失控时自动减小弱磁电流（`:736-741`）；
- 弱磁退出后**延迟关调制 1 秒**（`m_current_off_delay`，`:754`），防止调制振荡导致体二极管大电流。

## 10. 保护系统（分层）

### 10.1 硬件级（中断里最快，即时停机）

`mc_interface_mc_timer_isr()`（`mc_interface.c:1881`）：

| 故障 | 条件 | 故障码 |
|---|---|---|
| 过流 | `|i_abs| > l_abs_current_max` | `ABS_OVER_CURRENT`（`:1986-1994`） |
| 栅极驱动 | DRV 故障引脚 | `DRV`（`:1999-2006`） |
| 硬件刹车 | BRK/TIM break | `BRK`（`:2008-2016`） |
| 驱动供电 | 过压/欠压 | `GATE_DRIVER_OVER/UNDER_VOLTAGE`（`:2018-2026`） |
| 母线过/欠压 | **积分器判断持续越界**（抗毛刺） | `OVER/UNDER_VOLTAGE`（`:1904-1927`） |

### 10.2 温度/转速级（1 kHz 任务）

`update_override_limits()`（`mc_interface.c:2245`）：

- MOSFET 温度：`l_temp_fet_start` 开始降流 → `l_temp_fet_end` 归零并报 `OVER_TEMP_FET`（`:2340-2364`）；
- 电机温度：同理 `OVER_TEMP_MOTOR`（`:2366-2390`）；
- 加速时**放宽温度限流**保证制动能力（`:2392-2417`）；
- 超速/欠速故障：`OVERSPEED`/`UNDERSPEED`/`ABS_OVERSPEED`（`:2443-2453`）。

### 10.3 故障处理与恢复

`mc_interface_fault_stop()` → 发事件给 `fault_stop_thread`（`mc_interface.c:2959`）→ 记录故障现场（电流/电压/占空比/转速/温度/换相步）→ `stop_pwm`。

**恢复**：`m_ignore_iterations` 倒计数（`m_fault_stop_time_ms` 时长）到 0 且 DRV 无故障 → `m_fault_now` 自动清零（`:2586-2594`），之后才能重新输入。

### 10.4 软件看门狗

ISR 里 `timeout_feed_WDT(THREAD_MCPWM)`（`mcpwm_foc.c:3018`）——线程卡死触发 MCU 复位。

## 11. 加速/限流逻辑（"加速罗"的完整链路）

加速本质是**电流（转矩）指令经过层层限幅后进电流环**。所有限幅在 `update_override_limits()` 末尾用 `utils_min_abs` 取最小（`mc_interface.c:2526-2546`）：

```
lo_current_max = min(
    MOSFET温度限流,
    电机温度限流,
    转速上限限流,        // 高速区电流归零 (ERPM 截止)
    转速下限限流,
    启动电流衰减,        // 低速启动时电流折减
    加速温度降额,
    占空比限流,
    输入电流限流         // 电池电流闭环映射
)
```

再叠加：

- **输入电流限流**（电池侧）：`lo_in_current_max = min(瓦数限流 l_watt_max/v_in, 电池截止, BMS 限流)`（`:2471-2506`）；
- **输入电流映射**：实际输入电流超过 `l_in_current_map_start` 比例时动态压低 iq 上限（`:2513-2524`）；
- **dq 分配**：`iq` 限幅后保证 `√(id²+iq²) ≤ i_max`（`:3672-3674`）；
- **BLDC 占空比斜坡**：`m_duty_ramp_step` + 电流超限回退 `m_current_backoff_gain`（`mcpwm.c:1976-2090`）——这是"加速/减速斜坡"最直接的实现，防止突变。

```
   │  设置目标: duty / iq / speed_rpm / pos
   ▼
mc_interface (状态机 + 控制模式 + 故障检测)
   │  目标 → id_target / iq_target (经 10+ 重限幅)
   ▼
电流环 ISR (每个 PWM 周期)
   │  采样 → Clarke → Park → PI → 解耦 → 逆Park → SVPWM → PWM
   │            ▲
   │            └── 角度: 编码器/霍尔/磁链观测器/HFI + PLL
   ▼
电机 (三相逆变器 + BLDC/PMSM)
```
