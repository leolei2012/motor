# 文档目录

本目录存放本工程的文档资料，按类型分目录：

```text
docs/
├── 规范/                         工程规范（平台无关，可复用）
│   ├── README.md                  规范索引
│   ├── architecture.md            架构规范
│   └── coding_standard.md         编码规范
├── datasheet/                     芯片手册
│   └── stm32g474cb.pdf
├── 原理图/                        原理图与硬件资料
│   ├── DMG474_V1.0.pdf
│   ├── DMG474硬件参考手册_V1.0.pdf
│   ├── ATK-PD6010B_V1.0.pdf
│   └── ATK-DMG474_V1.0 IO以及接口分配表.xlsx
```

## 各目录说明

| 路径 | 说明 |
|---|---|
| `规范/` | 工程规范（架构 + 编码），见 [README](./规范/README.md) |
| `datasheet/` | 芯片数据手册 |
| `原理图/` | 原理图、硬件参考手册、IO 接口分配表 |
